# Передача проекта на локальную машину

Этот архив — полный проект. Распакуй, открой папку в Claude Code, и новая сессия
подхватит контекст сама: в корне лежит `CLAUDE.md`, его читают автоматически.

## Почему переезжаем из облака
Облачный контейнер отрезан от сети политикой egress-прокси. Проверено:

| хост | статус |
|---|---|
| `api.elevenlabs.io` | **заблокирован** (403 на CONNECT) |
| `commons.wikimedia.org`, `upload.wikimedia.org` | заблокирован |
| `www.loc.gov`, `archive.org` | заблокирован |
| `images.metmuseum.org`, `www.rijksmuseum.nl` | заблокирован |
| `registry.npmjs.org`, `fonts.gstatic.com` | доступен |

Плюс папка `reels-studio` на твоём компьютере облачной сессии не отдаётся — Remote Control
не обслуживает Windows-машины. Локально всё это снимается разом: ElevenLabs, архивы,
твои файлы, быстрый рендер на видеокарте.

## Установка

```bash
# 1. Node 22 и ffmpeg
#    Windows:  winget install OpenJS.NodeJS.LTS ; winget install Gyan.FFmpeg
#    macOS:    brew install node ffmpeg
node -v        # должно быть 20+
ffmpeg -version

# 2. Зависимости
cd reels-studio
npm install

# 3. Проверка
npm run check
npx remotion still style-guide out/style-guide.png
```

`node_modules` в архив не входит — ставится из `package.json` за полминуты.
Chromium для рендера Remotion скачает сам при первом запуске.

Ключ ElevenLabs (см. `docs/07-voice.md`):
```
Windows:  setx ELEVENLABS_API_KEY "sk_..."     затем перезапустить терминал
macOS:    export ELEVENLABS_API_KEY=sk_...
```
Потом `node scripts/voice.mjs voices` — найдёшь id своего клонированного голоса (помечен ★).

## Что уже сделано и проверено рендером
- Дизайн-система «Архив»: палитра, 9 ступеней кегля, сетка, безопасные зоны Reels,
  3 грейда, плёночный слой. Образец: `out/style-guide.png`.
- 3 регистра подачи: Хроника, Коллаж, Галерея.
- 10 переходов, раскладка сцен внахлёст.
- 10 типов сцен.
- Библиотека: 17 графических элементов, нарисованных кодом. Образец: `out/elements.png`.
  Вставляются в любую сцену полем `decor` — проверено рендером.
- Два демо-сценария. `demo-chronicle` отрендерен целиком: 23.8 с, 1080×1920.
- `npm run check` — проверка сценариев до рендера.
- Шрифты с кириллицей и фактуры лежат локально, рендер не ходит в сеть.
