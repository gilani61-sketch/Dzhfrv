# reels-studio — инструкция для Claude Code

Студия вертикальных роликов для Instagram о брендах, их происхождении и искусстве.
Ролик собирается из JSON-сценария на Remotion. Дизайн-система одна на все ролики.

## Главное правило
**От ролика к ролику меняется только `content/<slug>.json`.** Всё остальное — система.
Если для нового ролика хочется поправить `src/` — остановись и спроси: это разовая прихоть
или в системе действительно дыра. Разовые правки в `src/` убивают узнаваемость аккаунта.

Единственный источник правды по значениям — `src/design/tokens.ts`. Не дублируй числа в сценах.

## Рабочий цикл
1. Пользователь присылает текст или идею.
2. Разбиваешь на сцены → пишешь `content/<slug>.json` (типы сцен — в `docs/03-scenes.md`).
3. `npm run check` — проверка до рендера. Красный — не рендерить.
4. `node scripts/sheet.mjs <slug> 12` — контактный лист, согласовать композицию.
5. `npm run render -- <slug> --preview` — черновик, согласовать ритм.
6. `npm run render -- <slug>` — финал в `out/<slug>.mp4`.

Полный рендер дорогой. Согласование всегда идёт по контактному листу и черновику.

## Чего не делать
- Не вводить четвёртый акцентный цвет и пятую гарнитуру.
- Не изобретать кегли между ступенями шкалы.
- Не добавлять переходы сверх десяти в `src/transitions/`.
- Не ставить план короче 1.5 с и подпись длиннее 6 слов.
- Не класть ничего важного ниже 1520 px и выше 180 px — там интерфейс Instagram.
- Не подменять `staticFile(...)` на пути вида `/media/...` — при рендере будет 404.
- Не трогать `public/fonts` и `public/textures` без причины: они детерминированы,
  и от них зависит воспроизводимость всех прошлых роликов.

## Окружение
- Node 22, ffmpeg в PATH, Chromium для рендера.
- Шрифты и фактуры лежат локально — рендер не ходит в сеть.
- Переменные для озвучки: `ELEVENLABS_API_KEY`, по желанию `ELEVENLABS_VOICE_ID`.
