# reels-studio

Студия вертикальных роликов для Instagram о брендах, их происхождении и искусстве.
Единая дизайн-система, три регистра подачи, сборка ролика из JSON-сценария.

**Принцип:** от ролика к ролику меняется только `content/<slug>.json`. Всё остальное — система, и она одна на все ролики.

## Быстрый старт
```bash
npm install
npm run check                       # проверить сценарии
npm run studio                      # превью и правка на таймлайне
npm run render -- demo-chronicle    # рендер в out/
```

## Регистры
- **Хроника** — чёрное поле, киноплоса 16:9, шапка «рубрика + бренд». Для движущегося материала.
- **Коллаж** — тёмная бумага, вырезки, гравюры, растр, рваные полосы. Когда материала мало.
- **Галерея** — паспарту, музейная этикетка, медленный наезд. Для искусства.
