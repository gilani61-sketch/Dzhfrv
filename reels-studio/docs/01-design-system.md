# Дизайн-система «Архив»

Единственный источник правды — `src/design/tokens.ts`. Этот файл описывает, что там лежит и почему.
Визуальный образец системы: `out/style-guide.png` (пересобирается командой `npx remotion still style-guide out/style-guide.png`).

## Холст
- **1080 × 1920, 30 fps.** Instagram Reels, вертикаль 9:16.
- Длина ролика: 20–45 с. Короче — не успеваем объяснить, длиннее — досматриваемость падает.

### Безопасные зоны
| Зона | Пиксели | Что там у Instagram |
|---|---|---|
| сверху | 180 | аватар, «Reels» |
| снизу | 400 | текст поста, звук, кнопки |
| по бокам | 72 | поле контента |
| справа | 180 | колонка лайк / коммент / шер |

**Опорные линии** (в `GRID`):
- `lockupTop = 360` — шапка «рубрика + бренд».
- `band = 644…1252` — киношная полоса 16:9 (высота 608).
- `captionBaseline = 1360` — верх строки подписи.
- `opticalCenter = 845` — оптический центр, выше геометрического.

Ничего важного ниже 1520 и выше 180. Проверка — включить `"guides": true` в сценарии.

## Типографика
Две рабочие гарнитуры + одна вспомогательная. Файлы лежат локально в `public/fonts` (кириллица + латиница), рендер не зависит от сети.

| Роль | Гарнитура | Зачем |
|---|---|---|
| заголовок, локап | **Playfair Display** | дидон, читается как вывеска начала века |
| подпись, рубрика | **Oswald** | узкий гротеск, плотная строка в нижней трети |
| служебное | **Inter** | мелкие метки, цифры |
| цитата | **Cormorant Garamond** | только для сцены `quote` |

### Шкала кегля
Восемь ступеней, между ними ничего не изобретаем.

| ступень | кегль | интерлиньяж | трекинг | где |
|---|---|---|---|---|
| `display` | 132 | 0.94 | −0.02em | обложка |
| `title` | 88 | 1.02 | −0.01em | крупная мысль |
| `brand` | 104 | 1.0 | 0 | имя бренда в локапе (курсив) |
| `quote` | 76 | 1.18 | 0 | цитата (курсив) |
| `caption` | 62 | 1.1 | 0 | подпись-субтитр, капсом |
| `body` | 44 | 1.34 | 0 | пояснение |
| `kicker` | 34 | 1.2 | 0.22em | рубрика, капсом |
| `label` | 26 | 1.2 | 0.30em | год, город, источник |
| `numeral` | 240 | 0.86 | −0.03em | год во весь кадр |

**Правила набора**
- Подпись-субтитр — всегда капсом, всегда по центру, всегда на `captionBaseline`.
- Переносы строк в заголовках ставим руками через `\n`. Авторазрыв ломает ритм.
- В одной сцене не больше двух ступеней шкалы.
- Висячая строка из одного слова — переписываем текст, а не уменьшаем кегль.

## Плёнка
Поверх всего и всегда, меняется только сила (значения в `FILM`, переопределяются в регистре):
- **зерно** — 4 тайла по кругу со случайным сдвигом, режим наложения `overlay`;
- **пыль и царапины** — 6 кадров, подменяются 6 раз в секунду, режим `screen`;
- **виньетка** — радиальная, без резкой границы;
- **дрожание кадра** 1.6 px и **мерцание экспозиции** 3.5% — плавный шум, не случайный по кадрам (иначе выглядит как глитч, а не как плёнка);
- кадр внутри «окна» увеличен на 0.6%, чтобы дрожание не обнажало край.

## Глубина
Одна тень на вырезку, одна на карточку. Свечения и градиентные обводки не используем — их не бывает на бумаге.
