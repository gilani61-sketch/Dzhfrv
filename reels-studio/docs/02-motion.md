# Система движения

Три слоя: **ритм** (сколько держать), **переход** (как сменить), **жест** (как появляется элемент внутри сцены).
Всё задано в `src/design/tokens.ts → TIME` и `src/transitions/`.

## 1. Ритм
Единица — **бит = 15 кадров = 0.5 c**. Любая длительность кратна биту.

| имя | кадры | секунды | когда |
|---|---|---|---|
| `shotMin` | 45 | 1.5 | предел; короче зритель не прочитает подпись |
| `shotShort` | 60 | 2.0 | перечисление, быстрый монтажный ряд |
| `shotMed` | 90 | 3.0 | рабочая длина плана |
| `shotLong` | 135 | 4.5 | цитата, финал, пауза перед выводом |

**Правило чередования.** Нельзя ставить подряд больше трёх планов одной длины — получается метроном. Схема, которая работает: `3 — 3 — 2 — 2 — 4.5 — 3`.

## 2. Переходы
Десять штук, больше не нужно. Длительность зашита — руками не трогаем.

| переход | кадры | что делает | где уместен |
|---|---|---|---|
| `cut` | 0 | встык | внутри монтажного ряда |
| `dip` | 6 | провал в чёрное | смена темы в «Хронике» |
| `flash` | 7 | склейка плёнки, засветка | перед годом, перед поворотом сюжета |
| `fade` | 12 | наплыв | «Галерея», спокойный переход |
| `paper` | 16 | рваная бумага наезжает снизу | «Коллаж», вход текстовой мысли |
| `slide` | 14 | сдвиг вбок | перечисление, «а потом» |
| `halftone` | 18 | проявка растровой точкой | вход коллажа, «печать» |
| `zoom` | 14 | наезд с подменой | усиление, крупный план |
| `shutter` | 14 | ламели затвора | до/после, сравнение |
| `filmroll` | 16 | протяжка плёнки вверх | финал, «листаем дальше» |

**Как это устроено.** Сцены лежат внахлёст ровно на длину перехода: входящая делает активное движение, уходящая — слабое (чуть темнеет, чуть уезжает). Вспышка и провал в чёрное рисуются поверх обеих. Поэтому склейка читается как одно событие, а не как две анимации.

**Выбор по умолчанию.** Если в сценарии не указан `in`, переход берётся из пула регистра по кругу (`transitionPool`). Это сразу даёт разнообразие без ручной работы. Указывай `in` только там, где нужен смысловой акцент.

**Чего не делаем.** Вращений 3D, кубов, «морфа» букв, зеркальных отражений, тряски на бите. Архив не трясётся.

## 3. Жесты внутри сцены
| жест | кадры | кривая | где |
|---|---|---|---|
| вход элемента | 10 | `archive` (0.16, 1, 0.3, 1) | заголовок, метка |
| быстрый вход | 7 | `archive` | слово подписи |
| выход | 8 | `archive` | всё |
| слово за словом | шаг 2 кадра | `archive` | подпись-субтитр |
| строка из-под маски | 14, шаг 4 | `archive` | крупная мысль, заголовок обложки |
| перещёлк цифры | 22, шаг 3 | `snap` (0.2, 0, 0, 1) | год |
| ход камеры | вся сцена | `drift` (0.4, 0, 0.6, 1) | Кен Бёрнс |

### Кривые
- `archive` — предмет кладут на стол: быстро стартует, мягко садится. Основная.
- `paper` — вес и инерция. Только для бумаги и сдвигов.
- `snap` — щелчок затвора. Только для цифр и вспышек.
- `drift` — равномерный дрейф. Только для камеры.

Пятой кривой нет.

## 4. Ход камеры по кадру
`move` в сцене: `push` (наезд 8.5%), `pull` (отъезд), `panL` / `panR` (панорама ±30 px), `driftUp`, `none`.

- Фото **всегда** с движением — статичное фото читается как сбой.
- Видео по умолчанию `none`: материал уже движется, второе движение даёт кашу.
- Внутри одного монтажного ряда направление не меняем на противоположное — это рывок.

## 5. Подпись
Слова появляются по одному с шагом 2 кадра, вверх на 14 px, с тенью. Первое слово — через 7 кадров после начала сцены.
Строка живёт столько же, сколько план: подпись не переживает кадр, к которому относится.

Длина подписи — **до 6 слов**. Всё, что длиннее, разбивается на две сцены.
