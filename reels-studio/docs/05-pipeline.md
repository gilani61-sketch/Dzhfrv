# Как собирается ролик

```
твой текст
   ↓  я разбиваю на сцены
content/<slug>.json          ← сценарий, единственное, что меняется от ролика к ролику
   ↓  Remotion: React → кадры
out/<slug>.sheet.png         ← контактный лист на согласование
   ↓  после правок
out/<slug>.mp4               ← 1080×1920, 30 fps, H.264
```

Дизайн-система, сцены и переходы живут в `src/` и от ролика к ролику **не меняются**. Именно поэтому сотый ролик выглядит как первый.

## Команды

```bash
npm install                         # один раз

npm run check                       # проверить сценарии до рендера
npm run studio                      # интерактивный Studio: таймлайн, превью, правка на лету
npm run new -- cartier-santos chronicle "История часов" "Cartier"
npm run render                      # все сценарии из content/
npm run render -- cartier-santos    # один
npm run render -- --preview         # черновик 540×960, быстрее примерно вчетверо
node scripts/sheet.mjs cartier-santos 12   # контактный лист из 12 кадров
npx remotion still style-guide out/style-guide.png   # пересобрать образец дизайн-системы
```

## Структура

```
reels-studio/
├── CONCEPT.md             концепция аккаунта
├── docs/                  дизайн-система, движение, сцены, бриф, ассеты
├── content/               сценарии роликов (JSON) — то, что растёт каждый день
│   ├── _template.json
│   ├── demo-chronicle.json
│   └── demo-collage.json
├── src/
│   ├── design/            tokens · easing · fonts · grade   ← дизайн-система
│   ├── schema/reel.ts     схема сценария (zod), она же документация полей
│   ├── styles/            три регистра подачи
│   ├── transitions/       десять переходов
│   ├── overlays/Film.tsx  зерно, пыль, виньетка, дрожание, засветка
│   ├── components/        типографика, медиа, бумага, направляющие
│   ├── scenes/            девять типов сцен
│   ├── Reel.tsx           раскладка по времени и сборка
│   └── StyleGuide.tsx     визуальный образец системы
├── public/
│   ├── fonts/             кириллица локально, рендер не зависит от сети
│   ├── textures/          бумага, зерно, пыль, растр — сгенерированы процедурно
│   └── media/             твои исходники: footage · stills · logos · audio
├── scripts/               render · sheet · new-reel
└── out/                   готовые mp4 и контактные листы
```

## Как устроена раскладка по времени
`src/Reel.tsx → layout()`:
1. Длительность сцены = `dur` из сценария, иначе значение регистра для этого типа сцены, не меньше `shotMin`.
2. Переход = `in` из сценария, иначе следующий из пула регистра.
3. Сцена ставится внахлёст с предыдущей ровно на длину перехода.
4. Общая длина ролика — конец последней сцены. Ничего вручную считать не нужно.

Поэтому правка `dur` у одной сцены не ломает остальные: всё пересчитывается само.

## Проверка перед сдачей
- `npm run check` — существуют ли файлы, не длинные ли подписи, выдержан ли ритм, влезает ли ролик в формат.
- `"guides": true` в сценарии — показать безопасные зоны и опорные линии. Ничего важного не должно попасть в красные поля.
- Контактный лист — композиция и читаемость.
- Черновик `--preview` — ритм и переходы.
- Полный рендер — только после этих трёх шагов.

## Производительность
Рендер идёт программным GL (в облачном контейнере нет видеокарты): **примерно 1 секунда на кадр**, то есть ролик на 25 секунд ≈ 12 минут. На машине с видеокартой — в разы быстрее. Поэтому согласование идёт по контактному листу и черновику, а полный рендер — один раз в конце.

## Пересобрать фактуры
```bash
python3 -I scripts/make-textures.py     # бумага, зерно, пыль, растр
python3 -I scripts/fetch-fonts.py       # пересобрать локальные шрифты из скачанного CSS
```
Фактуры детерминированы: один и тот же сид даёт тот же файл, так что пересобирать их обычно не нужно.

## Шрифты
`public/fonts/fonts.css` + локальные `.woff2` (кириллица и латиница). Добавить гарнитуру: положить `.woff2`, дописать `@font-face` в `fonts.css`, добавить семейство в список прогрева в `src/design/fonts.ts` и в `FONT` в `tokens.ts`.
