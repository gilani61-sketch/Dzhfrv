# Озвучка

Голос идёт через ElevenLabs. Синтез я не делаю сам — я вызываю твой аккаунт твоим ключом.

## Один раз: ключ и голос

```bash
# Linux / macOS
export ELEVENLABS_API_KEY=sk_...
# Windows PowerShell
setx ELEVENLABS_API_KEY "sk_..."     # потом перезапустить терминал
```

Посмотреть, какие голоса доступны, и найти свой клонированный:
```bash
node scripts/voice.mjs voices
```
Команда печатает id голосов (твои помечены ★) и список моделей с пометкой, где есть русский.
Нужный id кладём в `ELEVENLABS_VOICE_ID` — или в поле `"voiceId"` конкретного сценария, если
для этого ролика нужен другой голос.

Модель по умолчанию — `eleven_multilingual_v2`. Поменять: `ELEVENLABS_MODEL=...`.

## Как писать реплики
У каждой сцены появляется поле `say` — то, что говорит голос, пока эта сцена на экране.

```json
{ "type": "footage", "src": "media/footage/02.mp4",
  "caption": "Лётчику нужна была свободная рука",
  "say": "В девятьсот первом бразилец Сантос-Дюмон пожаловался Луи Картье: в полёте невозможно достать часы из кармана." }
```

**`say` и `caption` — разные вещи.** Подпись — это два-три слова крупно на экране. Реплика — живая речь. Дублировать подпись голосом не нужно: зритель прочитает быстрее, чем голос договорит.

Числа лучше писать словами («в девятьсот четвёртом»), иначе модель прочитает их по-своему.

## Сборка
```bash
node scripts/voice.mjs say cartier-santos --dry    # посмотреть, что уйдёт; кредиты не тратятся
node scripts/voice.mjs say cartier-santos          # озвучить
node scripts/voice.mjs say cartier-santos --fit    # озвучить и подогнать длительности сцен
node scripts/voice.mjs say cartier-santos --scene 3  # переозвучить только третью сцену
```

Каждая сцена синтезируется **отдельным файлом** в `public/media/audio/vo/<slug>/NN.mp3`. Это даёт две вещи: длительность каждой реплики известна точно, и переозвучить одну сцену можно, не трогая остальные. Потом всё склеивается в одну дорожку `public/media/audio/vo/<slug>.mp3`, и путь к ней прописывается в сценарий сам.

С `--fit` длительность каждой сцены становится равной её реплике плюс 0.35 с тишины, чтобы склейка не обрезала голос. Сцены без `say` сохраняют свою длительность — там голос молчит.

## Порядок работы
1. Написал сценарий с `say` → `--dry`, проверил текст.
2. `--fit` → длительности сцен встали под голос.
3. `npm run check` → ритм и формат.
4. Контактный лист → черновик → финал.

Если потом правишь текст одной сцены — `--scene N`, затем снова `--fit`.

## Музыка под голосом
`musicGain` в сценарии: `0.22` когда есть голос, `0.5` когда ролик без голоса. Выше 0.3 под голосом речь начинает тонуть.

## Если ключа нет
Ролик собирается без голоса: подписи плюс музыка. Это рабочий формат, половина архивных роликов так и живёт.
