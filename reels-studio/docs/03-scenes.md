# Регистры и сцены

## Регистры
Задаются полем `"style"` в сценарии. Каждый регистр — это готовый набор: грейд, фон, кадрирование по умолчанию, пул переходов, сила плёнки, длительности. Описаны в `src/styles/index.ts`.

### `chronicle` — Хроника
Чёрное поле, киношная полоса 16:9 в верхней трети, шапка «рубрика + бренд», подпись под полосой.
Грейд: тёплая плёнка, контраст 1.06, насыщенность 0.82, сепия 0.14.
Переходы: `dip → fade → dip → flash → zoom → dip`.
**Берём, когда есть движущийся материал.**

### `collage` — Коллаж
Тёмная бумага, вырезки с рваным краем, растровая точка, полосы, параллакс по глубине.
Грейд: контраст 1.14, насыщенность 0.7, сепия 0.22, умножение тёплой заливкой.
Переходы: `paper → halftone → slide → paper → shutter → filmroll`.
**Берём, когда материала мало, а мысль есть.**

### `gallery` — Галерея
Светлое паспарту, деревянная рамка, музейная этикетка слева внизу, очень медленный наезд на деталь.
Грейд: почти чистый, сепия 0.05 — живопись нельзя красить.
Переходы: `fade → zoom → fade → slide`.
**Берём для искусства: картина, объект, здание.**

## Сцены
Поле `"type"`. Все поддерживают общие ключи: `dur` (секунды), `in` (переход), `caption`, `label`, `lockup`.

### `cover` — обложка
Первые 1.5 секунды решают всё.
```json
{ "type": "cover", "title": "Часы, которые\nпридумали\nдля неба",
  "kicker": "ПАРИЖ · 1904", "brand": "Cartier",
  "bg": { "src": "media/footage/01.mp4", "move": "push" }, "dur": 3.2 }
```
`title` разбивай `\n` вручную, 2–4 строки. Локап на обложке скрыт — его роль играет сам заголовок.

### `footage` — видеоплан
```json
{ "type": "footage", "src": "media/footage/02.mp4", "from": 1.5,
  "fit": "band", "move": "none", "caption": "Лётчику нужна была свободная рука",
  "label": "ПАРИЖ, 1901", "dur": 3 }
```
`fit`: `band` (полоса 16:9), `full` (на весь кадр), `card` (карточка с тенью). `from` — секунда старта в исходнике.

### `still` — фотоплан
То же, но картинка. `move` обязателен, по умолчанию `push`.

### `numeral` — год во весь кадр
```json
{ "type": "numeral", "value": "1904", "note": "Картье делает часы, которые не нужно доставать из кармана",
  "bg": { "src": "media/footage/03.mp4", "move": "pull" }, "in": "flash", "dur": 2.6 }
```
Цифры перещёлкиваются до нужной. Один год на ролик — иначе приём стирается.

### `statement` — крупная мысль
```json
{ "type": "statement", "text": "Так наручные часы\nперестали быть\nженским украшением.",
  "bg": "charcoal", "align": "left", "in": "paper", "dur": 3 }
```
Строки выезжают из-под маски. 3–4 строки максимум.

### `quote` — цитата
```json
{ "type": "quote", "text": "Вещь выживает,\nесли решает\nчью-то задачу.", "author": "правило архива", "dur": 3.6 }
```

### `collage` — коллаж
```json
{ "type": "collage", "bg": "charcoal", "headline": "Сначала был\nзаказ.",
  "caption": "Ремесло становится производством",
  "strips": [ { "y": 58, "h": 7, "tone": "cream" }, { "y": 84, "h": 5, "tone": "gold" } ],
  "layers": [
    { "src": "media/stills/factory.png", "x": 50, "y": 34, "w": 86,
      "depth": 0.2, "treat": "duotone", "anim": "rise", "rotate": -1.5 }
  ], "dur": 3.2 }
```
- `x`, `y`, `w` — проценты холста; `x`/`y` — центр слоя.
- `depth` 0…1 — сила параллакса: 0 задний план, 1 передний.
- `treat`: `duotone` (сепия), `engrave` (гравюра, жёсткий контраст), `cutout` (с бумажной рубашкой), `none`.
- `anim`: `rise`, `slideL`, `slideR`, `pop`, `swing`, `none`.
- `strips` — рваные полосы бумаги, `y`/`h` в процентах высоты. Ниже `y: 78` не ставим — там интерфейс Instagram.
- `headline` занимает полосу 420–640 px и получает градиентную подложку, так что читается поверх любой вырезки. Слои с `y` в районе 20–30% под него всё равно лучше не ставить.

### `split` — было / стало
```json
{ "type": "split", "in": "shutter",
  "top": { "src": "a.jpg", "move": "panL" }, "bottom": { "src": "b.jpg", "move": "push" },
  "topLabel": "БЫЛО", "bottomLabel": "СТАЛО", "dur": 3.2 }
```

### `gallery` — картина в паспарту
```json
{ "type": "gallery", "src": "media/stills/painting.jpg",
  "artist": "ИМЯ ХУДОЖНИКА", "work": "Название работы", "year": "1888, холст, масло",
  "detail": { "x": 12, "y": 8, "zoom": 1.8 }, "dur": 5 }
```
`detail` — куда наезжать: смещение в процентах и кратность.

### `outro` — финал
```json
{ "type": "outro", "line": "Бренды начинаются\nс чужой проблемы", "cta": "СОХРАНИ · ПОДПИШИСЬ", "dur": 3 }
```
Хэндл берётся из поля `handle` ролика.

## Каркас ролика, который работает
```
cover        3.2   крючок
footage      3.0   проблема
numeral      2.6   год
footage      2.6   решение
statement    3.0   что изменилось
footage      2.6   деталь
still        3.0   как выглядит сейчас
quote        3.6   вывод
outro        3.0   подпись
```
Итого ~27 с. Это опорная схема, а не закон — но если не знаешь, с чего начать, начни с неё.
