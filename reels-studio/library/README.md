# Библиотека

Всё, что переиспользуется между роликами. Делится на две части: **метаданные** лежат здесь, **файлы** — в `public/library/`, чтобы их видел рендер.

```
library/                       метаданные (не отдаются в рендер)
├── brands/<slug>.json         карточка бренда: факты, годы, палитра, права
├── brands/_template.json      пустая карточка
└── palettes/eras.json         палитры эпох

public/library/                файлы (отдаются в рендер через staticFile)
├── elements/*.svg             графические элементы + catalog.json
├── logos/                     логотипы брендов
├── backgrounds/               фоны и подложки
└── characters/                вырезанные фигуры, персонажи
```

## Элементы
17 штук, **нарисованы кодом**, не скачаны: штампы, рамки, линейки, стрелки, скрепка, скотч, перфорация плёнки, лучи, лента, каталожная карточка. Пересобрать: `node scripts/make-elements.mjs`. Смотреть: `out/elements.png`.

Вставляются в любую сцену полем `decor`:
```json
"decor": [
  { "name": "stamp-archive.svg", "x": 78, "y": 26, "w": 26,
    "rotate": -8, "tone": "gold", "anim": "stampIn", "start": 14 }
]
```
`x`, `y`, `w` — проценты холста, `x`/`y` — центр. `tone` — любой цвет палитры. `anim`: `stampIn`, `fadeIn`, `pop`, `draw`, `drift`, `none`.

Цвет не зашит в файл: SVG работает как маска, краска берётся из палитры. Поэтому один элемент годится для всех трёх регистров.

## Карточки брендов
Один бренд — один JSON. Это и заготовка сценария, и память: факты не придётся искать второй раз.

Поле `beats` — хронология. У каждого пункта есть `verified` и `source`. **Пока `verified: false`, факт в ролик не идёт.** Я вношу то, что знаю, но помечаю непроверенным — проверка на источниках за тобой.

Поле `rights` — кто владеет логотипом и кадрами. Заполняется до того, как ролик уходит в публикацию.

## Логотипы, фоны, персонажи
Эти папки пустые: их наполняешь ты. Я не скачиваю чужие логотипы и не генерирую изображения.

- `logos/` — png с прозрачностью, длинная сторона от 800 px, имя = slug бренда.
- `backgrounds/` — jpg от 1600 px по длинной стороне.
- `characters/` — вырезанные фигуры, обязательно png с альфой.

Имена латиницей, без пробелов: `cartier-logo.png`, `paris-1900.jpg`.
