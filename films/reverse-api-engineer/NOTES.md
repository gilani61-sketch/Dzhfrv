# Reverse API Engineer — раскадровка

Вертикаль 1080×1920, 30 fps, 26.0 с (780 кадров).
Один непрерывный мир: восемь станций вдоль коридора по −Z,
камера едет по единому сплайну и ни разу не режется.

| # | t, с | z | что на экране |

## Приёмы

- **Фокус** всегда привязан к активной станции, на переходах — рэк-фокус,
  диафрагма на разгоне открывается (`uAperture` 0.075 → 0.15).
- **Смаз** — 3 суб-кадра на кадр, выдержка 0.72.
- **Разгон** между станциями даёт whoosh: растягиваются пакеты,
  поднимается экспозиция, усиливается аберрация, появляется data-glitch.
- **Тёплый блок** только один (слом парсера) — всё остальное холодное,
  чтобы этот момент читался.

## Звук

Синтез в numpy: дрон 55 Гц, райзер перед каждым разгоном, бум на прилёте,
тики набора на двух печатающих блоках, бой стекла на сломе, финальный удар
и шиммер на хвосте. Нормализация −14 LUFS / −1 dBTP.
