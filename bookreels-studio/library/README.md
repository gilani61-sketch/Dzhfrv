# Библиотека

Всё, из чего собирается ролик, кроме самих кадров. Текстуры и оверлеи
генерируются кодом (`scripts/gen_library.py`), а не лежат мёртвыми файлами —
значит их можно перегенерировать с другими параметрами, а не искать заново.

`index.json` — список всего, что сейчас есть. Обновляется той же командой.

```bash
python3 scripts/gen_library.py          # перегенерировать всё
python3 scripts/gen_library.py paper    # только бумагу
python3 scripts/gen_library.py index    # только индекс
```

## Разделы

| Папка | Что | Как подключить |
|---|---|---|
| `palettes/` | 5 палитр по рубрикам | `palette: nocturne` в шапке `script.md` |
| `backgrounds/` | бумага, холст, градиенты | фон карточек цитат и титров |
| `overlays/` | виньетки, зерно, пыль, засветки, скрим | `overlay: dust-01.png` |
| `elements/` | рамки, разделители, кавычки | внутри компонентов |
| `brand/` | знаки канала (клаппер, книга, рама) | `endcard:` и плашки |
| `characters/` | описания персонажей для промптов | `{{char:martin}}` в `shotlist.md` |
| `voices/` | реестр голосов ElevenLabs | `- [character-male] реплика` |
| `music/`, `sfx/` | музыка и звуки | кладёшь файлы сама |

## Палитры

`literature` · `painting` · `biography` · `nocturne` · `punch`

Кадр почти всегда цветной сам по себе, поэтому палитра управляет только
текстом, плашками, подложками и фоном карточек — не самой картинкой.

## Оверлеи — чем они полезны

| Файл | Зачем |
|---|---|
| `vignette-*.png` | увести взгляд в центр; `cine` — самый мягкий |
| `grain-*.png` | **главный склеивающий приём**: зерно поверх всего делает AI-картинку и наложенный текст одним изображением |
| `dust-*.png` | пылинки и царапины — «архивная плёнка» для биографий |
| `leak-*.png` | засветки; подключаются с `blend: screen` и лёгким дрейфом, чтобы дышали |
| `scrim-bottom.png` | готовая подложка под субтитр, если градиента в компоненте мало |

Больше двух оверлеев на сцену — перебор: кадр мутнеет и теряет контраст.

## Персонажи

`characters/bible.json` — самое недооценённое место библиотеки. AI-ролики
разваливаются именно здесь: в кадре 7 герой выглядит другим человеком.
Лечение одно — описание внешности пишется один раз и вставляется в каждый
промпт **дословно**, без синонимов и перестановок слов.

Заводи персонажа один раз на проект и не меняй ему одежду по ходу.
Если переодеть надо по сюжету — это второй персонаж: `martin-young` / `martin-rich`,
у которого лицо и телосложение описаны теми же словами.

## Голоса

`voices/voices.json` хранит `voice_id` — это не секрет, его можно держать
в репозитории. **API-ключ здесь не хранится** и не должен сюда попадать:
он читается из переменной окружения `ELEVENLABS_API_KEY`.

Роль указывается в начале реплики: `- [character-male] Я напишу об этом`.
Реплика без роли читается голосом по умолчанию.

## Чего в библиотеке нет

Музыки и звуков — их надо класть руками, я не могу их скачивать
или генерировать. И самих кадров: их генеришь ты по промптам из `shotlist.md`.
