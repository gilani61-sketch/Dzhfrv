# Музыка

Клади сюда треки, под которые монтируешь. Формат: mp3 или wav, желательно
без вокала — он спорит с озвучкой и с субтитрами.

Называй по настроению, а не по исполнителю:
`calm-piano-01.mp3`, `tense-strings-02.mp3`, `warm-guitar-01.mp3`.

Подключается строкой в `script.md`:

    music: calm-piano-01.mp3

Движок сам приглушит трек до −26 LUFS и пригнёт ещё на 9 dB под голосом.

## Про права

Instagram глушит и блокирует ролики с чужой музыкой. Для канала, который
растят всерьёз, бери лицензионное: Epidemic Sound, Artlist, Uppbeat
(у последнего есть бесплатный тариф с указанием автора).

Я не могу скачивать музыку — положи файлы сюда сама.
