# Звуковые элементы

Короткие звуки: перелистывание страницы, скрип пера, шум моря, тиканье часов.
Один-два на ролик, не больше — иначе получается радиоспектакль.

Называй по действию: `page-turn.wav`, `pen-scratch.wav`, `ocean-waves.wav`.

Подключение — в `scenes.json` у сцены:

    "sfx": [{ "src": "page-turn.wav", "at": 0.2, "gainDb": -18 }]

Я не могу генерировать или скачивать звуки — положи файлы сюда сама.
Бесплатные источники: freesound.org, zapsplat.
