# Пайплайн: от текста до готового Reels

Семь шагов. Твои — 1, 3 и 7. Остальное делаю я.

```
  ТЫ: текст/биография
        │
        ▼
  ┌─────────────────┐
  │ 1. СЦЕНАРИЙ     │  я режу текст на монтажные фразы      → script.md
  └─────────────────┘     3–7 слов на кадр, 10–16 кадров
        │
        ▼
  ┌─────────────────┐
  │ 2. РАСКАДРОВКА  │  я пишу промпты под каждый кадр       → shotlist.md
  └─────────────────┘     в едином визуальном стиле
        │
        ▼
  ┌─────────────────┐
  │ 3. КАРТИНКИ     │  ТЫ генеришь в Midjourney/Kling/Sora  → shots/*.jpg
  └─────────────────┘     и кладёшь в папку проекта
        │
        ▼
  ┌─────────────────┐
  │ 4. ОЗВУЧКА      │  ElevenLabs твоим голосом             → voice.mp3
  └─────────────────┘     + точные тайминги                    timings.json
        │
        ▼
  ┌─────────────────┐
  │ 5. СБОРКА       │  тайминги ложатся на субтитры         → scenes.json
  └─────────────────┘

        │

  ┌─────────────────┐
  │ 7. ПУБЛИКАЦИЯ   │  ТЫ выкладываешь                      → Reels
  └─────────────────┘
```

---

## Шаг 1. Сценарий

Ты даёшь текст — я режу его на монтажные фразы. Правила реза:

- **Один кадр — одна мысль.** Не предложение, а мысль: «Редакции возвращали его рассказы».
- **3–7 слов.** Длиннее — не читается на телефоне за 2.5 секунды.
- **Без вводных.** Не «Следует отметить, что Мартин», а «Мартин».
- **Глагол в каждой фразе.** Фраза без глагола не двигает историю.
- **Первая фраза — крючок.** Не «Роман вышел в 1909 году», а «Он утонул на пике славы».
- **Последняя — удар.** «Но сам Мартин — уже нет».

Длина ролика: **40–70 секунд**, это 10–16 кадров. Короче — не успевает зацепить,
длиннее — досматривают единицы.

Формат `script.md` — это одновременно сценарий, раскадровка и текст для озвучки:

```markdown
# Мартин Иден
author: Джек Лондон
mode: cinematic
preset: reel

## 01.jpg
- Он пришёл в этот дом матросом
- и остался в нём навсегда

## 02.jpg
- Руфь сначала ждала
```

`## файл` = сцена. `- строка` = один субтитр и одна реплика озвучки.

## Шаг 2. Раскадровка

Я пишу промпт под каждый кадр в `shotlist.md`. Единый стиль держится
за счёт общего префикса из `docs/visual-prompts.md` — без него кадры
«поедут» и ролик развалится на открытки.

## Шаг 3. Картинки — твоя часть

**Я не могу генерировать изображения и видео.** У меня нет доступа к
Midjourney, Kling, Sora, Runway. Ты берёшь промпты из `shotlist.md`,
генеришь и складываешь в `projects/<slug>/shots/` под именами `01.jpg`, `02.jpg`…

Требования: вертикаль 9:16, минимум 1080×1920. Можно и видео —
`01.mp4` вместо `01.jpg`, движок поймёт и не станет накладывать свой Ken Burns.

## Шаг 4. Озвучка

```bash
export ELEVENLABS_API_KEY=твой_ключ
python3 scripts/tts_eleven.py projects/<slug> --voice-id <id_твоего_голоса>
```

Реплики кэшируются: правка одной строки не перегенерит весь ролик.

**Если озвучки не надо** (референс «Мартин Иден» вполне может быть без голоса —
только музыка и субтитры) — просто пропусти шаг. Длительности посчитаются
по длине текста.

## Шаг 5–6. Сборка и рендер

```bash
python3 scripts/build_scenes.py projects/<slug>
bash scripts/render.sh <slug>
```

Готовый файл: `projects/<slug>/out/<slug>.mp4`.

## Правка

Что-то не так — правится в одном месте:

| Проблема | Где править |
|---|---|
| Текст, тайминг фразы | `script.md` → пересобрать |
| Кадр не тот | заменить файл в `shots/` → пересобрать |
| Шрифт, размер, цвет | `brand/tokens.json` |
| Скорость камеры, переходы | `brand/tokens.json` → `motion` |
| Вёрстка титра/субтитра | `engine/src/components/` |
