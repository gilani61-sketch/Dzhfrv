# BookReels Studio — контекст проекта

Этот файл читает Claude Code при старте сессии в этой папке. Он описывает,
что здесь происходит, чтобы не пришлось объяснять заново.

## Что это

Конвейер для Instagram Reels про книги, живопись и биографии художников.
Владелец канала — Юлия Польская, `@juliapolskayaa`, ~227 тыс. подписчиков,
рубрики: экранизация литературы нейросетями.

Вход: текст или биография от пользователя. Выход: готовый ролик 1080×1920.

## Откуда взялась дизайн-система

Снята замером по трём референсам, которые прислал пользователь
(кадры лежат в `refs/frames/`, разбор — в `refs/analysis.md`).

Главный референс — её собственный ролик «Мартин Иден». Шрифт заголовка
опознан как **Futura PT Light** по трём признакам: наклонные боковые штрихи
у «М», острая вершина «А», треугольная «Д». Заменён на **Jost 200** —
открытый аналог с кириллицей. Montserrat проверялся и отклонён:
у него «М» с вертикальными штрихами.

**Не меняй шрифт и типографику без запроса** — они выверены по кадрам.

## Архитектура

```
script.md  →  build_scenes.py  →  scenes.json  →  Remotion  →  mp4
   ↑                ↑
 текст        timings.json (из озвучки, если есть)
```

- `script.md` — единственный файл, который правит человек. Это одновременно
  сценарий, раскадровка и текст для озвучки.
- `scenes.json` генерируется, **руками не трогать**.
- `brand/tokens.json` — все размеры, цвета, тайминги анимации.
  Движок читает его напрямую; правки стиля идут сюда, а не в компоненты.
- `library/` — палитры, текстуры, оверлеи, знаки, реестры персонажей и голосов.
  Текстуры генерируются `scripts/gen_library.py`, а не лежат бинарниками.

## Команды

```bash
bash scripts/new_project.sh <slug> "Название" "Автор"
python3 scripts/tts_eleven.py projects/<slug>        # озвучка (нужен ключ)
python3 scripts/build_scenes.py projects/<slug>      # сборка спеки
bash scripts/render.sh <slug>                        # рендер + звук
cd engine && npm run studio                          # визуальный предпросмотр
```

## Что НЕ делает движок

**Не генерирует картинки и видео.** Доступа к Midjourney / Kling / Sora нет.
Кадры генерирует пользователь по промптам, которые Claude пишет в `shotlist.md`.
Это единственный ручной шаг конвейера — не пытайся его обойти и не подставляй
заглушки вместо настоящих кадров.

## Состояние озвучки

Скрипт `scripts/tts_eleven.py` написан и готов: несколько голосов в одном
ролике, кэш реплик по хэшу, тайминги под субтитры.

В облачной сессии, где проект собирался, он **не запускался ни разу**:
там не было ключа, а прокси блокировал `api.elevenlabs.io` (403).
Локально этого ограничения нет — нужен только ключ:

```bash
export ELEVENLABS_API_KEY=...
python3 scripts/tts_eleven.py projects/demo --list-voices   # узнать voice_id
```

Полученные `voice_id` вписать в `library/voices/voices.json`.

Имя модели там намеренно не прописано: есть `modelPreference`, скрипт
спрашивает у API доступные модели и берёт первую из списка. Пользователь
просил новейшую версию — она подхватится сама, если доступна аккаунту.
**Не хардкодь имя модели**, проверяй через `--list-models`.

## Правила текста для роликов

1. Один кадр — одна мысль. Субтитр 3–7 слов, **одна строка**
   (до 26 знаков, иначе уедет на вторую — сборщик предупредит).
2. Капс, трекинг 0.18 em, без точки в конце, тире длинное «—».
3. Первая фраза — крючок, последняя — удар.
4. Длина ролика 40–70 секунд = 10–16 кадров.
5. В каждой фразе глагол. Без вводных оборотов.

## Что ещё не сделано

  стиль откалиброван только по типографике, но не по его почерку.
  Запрос описан в `docs/feeding.md`.
- `library/voices/voices.json` — `voice_id` не заполнены.
- `library/music/` и `library/sfx/` пустые: файлы кладёт пользователь.
- Шаблоны под отдельные рубрики (книга / картина / биография) не разведены.
