# Эталон

`demo-reference.mp4` — как выглядит ролик, собранный этим движком:
титр, субтитры, плашка с датой, карточка цитаты, финальная плашка,
палитра `nocturne`, засветка и пыль.

Кадры в нём — вырезки из акварельного референса, то есть заглушки.
Важна не картинка, а то, что поверх неё.

Собран из `projects/demo/script.md`. Проверить, что у тебя так же:

```bash
bash scripts/render.sh demo
```
